# Private AI Assistant

A hybrid edge-brain AI assistant system using a Raspberry Pi for audio I/O and a local computer for RAG-based processing.

## Architecture

- **Brain Server** (Computer): FastAPI + Ollama (Llama 3) + ChromaDB
- **Edge Client** (Raspberry Pi): Picovoice Porcupine + ElevenLabs TTS
